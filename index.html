📖 About Attendance Risk Predictor

First-Year B.Tech CSE Project

Why this project? At Lovely Professional University (LPU), maintaining at least 75% attendance is mandatory under the UMS academic guidelines to receive the End-Term Examination (ETE) hall ticket and avoid debarment. Students frequently juggle continuous assessment (CA) tasks, lab practicals, sports, and technical fests, making it tricky to know whether taking an upcoming leave will trigger a warning or debarment.

This web application was built by a first-year Computer Science & Engineering student to solve this exact problem with pure client-side web technologies. No backend or server is required; all your records are stored safely in your own browser.

🛠️ Core Programming Concepts Used in this Project:

  • Semantic HTML5: Clean document structuring with accessibility and responsiveness in mind.
  • CSS3 Modern Layouts: Responsive Flexbox, CSS Grid, custom color variables, and Dark/Light themes.
  • Vanilla JavaScript DOM Manipulation: Dynamic card creation, event listeners, and interactive UI states.
  • JavaScript Objects & Arrays: Modeling subjects as structured records and computing overall averages with loops.
  • Browser localStorage API: Persistent data storage so your attendance stays intact when you refresh or revisit.
  • Discrete Math & Edge-Case Handling: Formulas using Math.floor() and Math.ceil() to compute required attendance and allowable skips.
  • Chart.js CDN: Rendering dynamic bar graphs with custom threshold colors.
